## Decided (27 Sep 2026)
1. `SEED.md` lives apart from `roots_seed.md` (identity vs operational spec).
2. English is canonical at the repo root; Spanish and French versions alongside.
3. Forest = the perceiving ecosystem (htree) + the modules it connects.
4. Roots = the Tree's memory; **Micielo** = the network between Trees (the "shared field").
5. Flores = the whole reproductive organ: propagation **and** a public proposal/vote layer.
6. Branch = git branch / generation line; capabilities are Features; Buds = candidates; Fruits = releases.
7. Tree = unit of product identity (an access account is not a Tree).
